I build .NET database libraries and developer tools:

- **[DuckDB.NET](https://github.com/Giorgi/DuckDB.NET)** - native bindings and an ADO.NET provider for DuckDB
- **[DuckDB.ExtensionKit](https://github.com/Giorgi/DuckDB.ExtensionKit)** / **[SharpPostgres](https://github.com/Giorgi/SharpPostgres)** - DuckDB and PostgreSQL database extensions written in C# and compiled with .NET AOT
- **[EntityFramework.Exceptions](https://github.com/Giorgi/EntityFramework.Exceptions)** - typed exceptions for EF Core across five database providers
- **[EFCore.Visualizer](https://github.com/Giorgi/EFCore.Visualizer)** - query plans inside the Visual Studio debugger

**38M+ NuGet downloads**, **4,000+ stars**.

3x Microsoft MVP, based in Tbilisi.

These days I build through AI coding agents - Claude Code and Codex - including the instructions, skills and hooks that make them dependable on a real codebase.

🎤 I speak at international conferences - NDC London, NDC Copenhagen, KCDC, Voxxed Days, .NET Developer Days, Update Conference (Prague and Krakow), FabCon Europe, .NET Conf - about applied AI, Entity Framework Core and modern SQL, and I've been a guest on .NET Rocks!, Visual Studio Toolbox and the JetBrains OSS Power-Ups webinar. Sessionize Most Active Speaker 2023 and 2025 - [full talk history](https://giorgi.dev/talk/).

[Microsoft MVP](https://mvp.microsoft.com/en-US/mvp/profile/e96c7912-ea3e-4fde-b8d3-745d6b07b31b), [Top 1% on Stack Overflow](https://stackoverflow.com/users/239438/giorgi?tab=topactivity), and a member of the [Top 3% freelance software developers network](https://www.toptal.com/N5jr6J/worlds-top-talent).

**Working with now:** C#, .NET, Entity Framework Core, ASP.NET Core, PostgreSQL, SQL Server, DuckDB, AWS, Azure

**Also shipped:** ASP.NET MVC, Web API, WCF, .NET MAUI, Avalonia, WinForms, Oracle, REST, GraphQL, and many more.
